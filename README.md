# braytron.cz

Auto-updated guide to AI tools for 3D and manufacturing.

- `content/posts/` articles (Markdown)
- `data/tools.json` the tool shortlist
- `build.js` builds the site into `dist/` (no dependencies: `node build.js`)
- `AGENT.md` instructions for the scheduled news agent
- Every push to `main` builds and publishes to GitHub Pages at https://braytron.cz
